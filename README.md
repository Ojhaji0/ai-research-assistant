# AI Research Assistant

An AI-powered research assistant built with Python, Gemini, and Tavily.

## Features

- AI-powered research workflow
- Real-time web research using Tavily
- Source ranking based on relevance and source quality
- Research report generation
- Calculator tool
- Current time tool
- Automated tests with pytest
- Git-based version control
